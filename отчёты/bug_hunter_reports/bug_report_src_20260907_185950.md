### [!!] Full-Balance Sweep in Payout
- **File:** `LambdaHook.sol:437`
- **Severity:** HIGH
**Problem:** A payout path sends the full contract balance instead of the exact amount owed. If the contract holds other users' funds or uncollected fees, any caller triggers this path and drains everything parked in the contract. This is a confirmed High/Critical class in competitive audits (refund-all / sweep-all).
**Fix:** Pay the caller's exact tracked entitlement; never use address(this).balance or balanceOf(address(this)) as the payout amount.
