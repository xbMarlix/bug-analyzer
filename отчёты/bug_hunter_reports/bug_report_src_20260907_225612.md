**Problem:** Low-level .call/.delegatecall return value is not captured; failures are silently ignored.
EXPLOIT: An attacker can call `safeTransfer` or `safeTransferFrom` with a malicious token contract that reverts the call. The `require(success, ErrorsLib.TRANSFER_REVERTED);` and `require(returndata.length == 0 || abi.decode(returndata, (bool)), ErrorsLib.TRANSFER_RETURNED_FALSE);` checks will fail, but the low-level call result is not captured, allowing the attacker to silently ignore the failure and continue with the rest of the transaction.

**Fix:** Capture the return value: (bool success, ...) = target.call(...); then verify success.
