High Full-Balance Sweep in Payout confidence 100%
LambdaHook.sol:437 solidity_semantic
Problem: A payout path sends the full contract balance instead of the exact amount owed. If the contract holds other users' funds or uncollected fees, any caller triggers this path and drains everything parked in the contract. This is a confirmed High/Critical class in competitive audits (refund-all / sweep-all).
EXPLOIT: An attacker can call the `deposit` function with a large `liquidity` value and a small `amount0Max` and `amount1Max` to trigger the payout path. This will cause the contract to send the full contract balance to the caller, draining all funds.
Recommendation: Pay the caller's exact tracked entitlement; never use address(this).balance or balanceOf(address(this)) as the payout amount.
